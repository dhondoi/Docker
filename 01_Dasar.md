## Instalasi
- download [docker](https://docs.docker.com/get-started/get-docker/) dan install
- cek apakah sudah terinstal dengan perintah
  ```cmd
  docker version
  ```
## Docker Registry
- tempat menyimpan Docker Image
- salah satunya adalah [Docker Hub](https://hub.docker.com/)
- Buat Akun. Done.
